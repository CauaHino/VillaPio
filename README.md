# Nombre de tu Juego

## Objetivo
El jugador debe atravesar 3 desafiantes niveles superando obstáculos, saltando plataformas y derrotando enemigos para llegar a la meta. ¡Sobrevive conservando tus vidas y tu salud para completar la aventura!

## Controles
- **A / D o Flechas Izquierda/Derecha:** Mover al personaje.
- **Espacio:** Saltar.
- **W:** Ataque cuerpo a cuerpo.
- **F:** Lanzar proyectil (Consume 1 unidad de munición).

## Instrucciones para abrir y jugar
1. Extrae el contenido del archivo ZIP.
2. Abre Unity Hub.
3. Haz clic en "Add" (Añadir) y selecciona la carpeta del proyecto extraído.
4. Asegúrate de usar Unity 6 (o la versión exacta que hayas utilizado).
5. Ve a la carpeta `Assets/Scenes` y abre la escena `MainMenu` para iniciar la partida desde el principio.

## Mecánicas Principales
- **Salud y Vidas:** El personaje tiene 5 puntos de salud. Si pierde toda la salud, morirá y perderá 1 vida global. El progreso de vidas se mantiene al avanzar de nivel gracias al uso de variables estáticas.
- **Recursos:** El jugador puede encontrar recargas de salud y munición repartidas por el nivel para continuar luchando.
- **Enemigos:** Es necesario golpear a los enemigos varias veces para derrotarlos.

## Assets Utilizados
- **Tileset / Entorno:** PLATFORMER/METROIDVANIA ASSET PACK de Itch.io
- **Personaje principal:** PLATFORMER/METROIDVANIA ASSET PACK de Itch.io
- **Enemigos:** PLATFORMER/METROIDVANIA ASSET PACK de Itch.io
- **Efectos de sonido:** Game Sound Effects de mixkit
